MULTIPLAYER FLOW

1. Player opens game page
2. Client connects via WebSocket to game port
3. Server assigns 4-char room code (e.g. A3X7)
4. Up to 6 players join same room
5. Server validates all moves (authoritative)
6. State broadcast to all players in room
7. Spectators can watch without joining
