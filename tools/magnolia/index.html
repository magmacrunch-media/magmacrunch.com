magnolia

Lightweight C engine for Wii homebrew score-attack games. Handles initialization, input, rendering, scoring, audio, and the game state shell — so you only write the gameplay.

Getting Started

Clone and scaffold:

cd ~/game_dev
../magnolia/tools/new-game.sh my-game
cd my-game && make
