A client-side full-text search modal. No server required — searches a static JSON index.

## Architecture

```
Every page (nav.js) ──load──▶ assets/search.js ──fetch──▶ search-index.json
                                      │
                                      └── modal overlay with input + results
```

## Files

| File | Purpose |
|------|---------|
| `assets/search.js` | Search logic (409 lines) — IIFE, self-contained |
| `assets/search.css` | Modal styles — CRT green terminal aesthetic |
| `search-index.json` | Pre-built search index (generated by `make search-index`) |
| `scripts/build-search-index.js` | Index builder script |

## How It Works

1. `nav.js` injects `search.css` and `search.js` on every page with a `<nav>` element
2. `search.js` injects a search icon button into the nav bar
3. On open, fetches `search-index.json` (cached in memory after first load)
4. Performs weighted token search across all index fields
5. Renders grouped results by category with highlighted matches

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `/` | Open search |
| `Ctrl+K` / `⌘K` | Open search |
| `ESC` | Close search |
| `↑` / `↓` | Navigate results |
| `Enter` | Open selected result |

Shortcuts are disabled when focus is in an `<input>`, `<textarea>`, or `<select>`.

## Search Index Format

Each entry in `search-index.json`:

```json
{
  "t": "title",
  "c": "category",
  "u": "/path/to/page.html",
  "d": "description",
  "b": "body text (full content for deep search)"
}
```

### Fields

| Field | Weight | Description |
|-------|--------|-------------|
| `t` | 3.0 | Title — primary match field |
| `a` | 2.5 | Artist/author |
| `d` | 1.5 | Description |
| `b` | 1.0 | Body text — full page content |
| `c` | 0.5 | Category label |

### Categories

| Category | Label | Color |
|----------|-------|-------|
| `music` | MUSIC | Green |
| `song` | SONG | Green |
| `artist` | ARTIST | Cyan |
| `place` | PLACE | Rose |
| `label` | LABEL | Yellow |
| `contributor` | CONTRIBUTOR | Purple |
| `arcade` | ARCADE | Orange |
| `press` | PRESS | White |
| `tool` | TOOL | Green |
| `page` | PAGE | Dim |

## Scoring Algorithm

1. Query is tokenized into words (minimum 2 characters each)
2. For each index entry, check if ALL words appear in at least one field
3. Score = sum of field weights where all words match
4. Results sorted by score descending, capped at 12 results

## Result Rendering

- Results grouped by category with colored labels
- Matched text highlighted with green `<span>` tags
- Body text snippets shown when title doesn't match directly
- "matched:" phrase shown for body-only matches

## Building the Index

```bash
make search-index
# or
node scripts/build-search-index.js
```

Scans all HTML files in the repo, extracts text content, deduplicates by URL, and writes `search-index.json` to the site root.

## Opt-Out

Add `no-search` to `<body>` to disable search on any page:

```html
<body class="no-search">
```

## Styling

The modal uses a CRT green terminal aesthetic:
- Background: `#0a0a0a` with green border (`--mc-cereal-green`)
- Input text: green monospace (`Press Start 2P`)
- Results: category-colored labels, white titles, dim descriptions
- Active result: green left border + green background tint
- Scrollbar: green thumb on dark track

The search icon in the nav bar uses the page's `--nav-accent` color.
